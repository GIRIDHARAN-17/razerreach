# Remix of Sales ROI Calculator Template (76)

We are building the ultimate Sales ROI calculator to help our Sales Engineer easily calculate ROI based on the company they are talking to. 

We dont want people to be bored - it should be intuitive to use but fun and elevated like a designers opus magnum. Everything should be at their fingertips in real time. 

Use React, Tailwind CSS, Framer Motion for all animations. Smooth scroll with Lenis or locomotive-scroll. Micro-interactions on every interactive element.

It should be fully responsive across all devices.

Features:
It should include all of the features from https://roi-calculcator-demo.lovable.app/ but also allow them to add their own templates. They should be able to save anything as a new template. 

Investment parameters, projected returns should all, uh, automatically like adjust. Like there should be more parameters or pieces that make sense based upon the type of company they are talking to, to make it a lot easier. They should also be able to set like kind of their, their defaults, like it's gonna depend upon what their company is, right? And what product they're selling to determine like what the ROI is going to be. You know, 'cause it might be they're selling software, it might be they're selling services. So I want you to really think through this to create the most intuitive options and templates from the start, and then make them fully customizable. Everything should auto-save as well and persist. So, um, it's just gonna be a personal tool, so we wanna store all this in Lovable Cloud, but no auth should be needed. And then we want a new tab that they can tab over to, or like it can be in a second or in the same screen, but just in a different window that they can adjust and open it up or minimize it, that they can have access to everything they need to see. But this new tab will, um, should be doing a web search to get enriched detail, like information on that company he's talking to. So they should be able to like type in like their link or a little bit about them, and then you should be able to bring in information in how our product will be relevant to the customer that they're having the sales call with, you know?
